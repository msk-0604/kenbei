# 9. Phase 3機能

会社の施工知識が案件数とともに効いてくる段階。数百万〜数千万行を前提に、予測と提案を増やす。**実行は人間。**

## 予測（表示は必ず 予測）

- 工期遅延予測
- 人工超過予測
- 原価超過予測
- 赤字予測
- 工程異常の早期検知

モデルは Decision Engine の `model:*` 検出器として差し込む。UI は確率や根拠を出し、工事計画を上書きしない。

## 提案（表示は 推奨）

- 人員配置の候補
- 類似現場の注意事項パック
- 材料手配の前倒し候補
- 見積時の contingency 候補

## 規模

- `audit_logs` / `photos` メタのパーティション
- 類似の近似探索（HNSW 等）
- 読み取りレプリカ、Storage CDN
- テナント単位のエクスポート

## モバイル

- React Native / Expo（packages 共有、AIキーは持たない）
- カメラと音声のネイティブ品質

## エンタープライズセキュリティ

- SSO（SAML / OIDC）
- SCIM
- IP制限
- 端末制限
- MFA 必須化
- 顧客管理キー等は要件が出てから

## 乗り換え

- ANDPAD / KANNA 専用 Importer（公式エクスポートまたは顧客提供データ）
- 移行ウィザード（案件 → 写真 → 日報相当）

## やらないこと（プロダクトとして）

- 職人の代わりに現場判断を確定するオートパイロット
- 他社の「機能チェックリスト完全一致」
- UI への「AI」ブランドの露出強化
