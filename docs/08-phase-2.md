# 8. Phase 2機能

MVP のループが回ったあと、**判断の精度と乗り換え**を厚くする。

## 現場

- オフライン寄りのキャプチャキュー（電波が弱い現場）
- 必要資料の案件への紐付け改善
- 協力会社向けの作業範囲の明示
- 資格期限の注意（現場配置前）

## Graph を埋める

- 見積・実行予算の内訳
- 外注先と外注費の内訳
- 変更・追加の金額影響を財務へ反映
- 完工時の結果入力を、確認質問の延長で回収
- `org_daily_snapshots` による経営数値の安定表示

## Similar Projects Engine

- `project_features.embedding`（pgvector）
- ルール候補の再ランキング
- 「23件中8件で既設配管変更」のようなフラグ集計の定型化
- エンジン切替（rule_v1 / embedding_v1）を Org 設定で

## Decision Engine

- 材料不足（使用ペース vs 残）
- 人員不足（工程に対する配置）
- 見積異常値（類似帯から外れた請負）
- 粗利低下（予算消化ペース）
- 追加工事候補（類似の追加発生パターン）
- 過去トラブル類似（インシデント本文の検索。LLM要約は任意）
- シグナルへのフィードバックを検出器の閾値に反映（手動調整が主）

## 知識

- 類似案件開始時の自動表示を標準化
- キャプチャやインシデントから知識候補を抽出（確定は人間）

## インポート

- Excel の複数シート
- 列マッピングUI
- ANDPAD / KANNA の CSV エクスポート向けプリセット（スクレイピングはしない）
- 写真 EXIF と案件日程の自動突合精度向上

## 権限・組織

- カスタムロール編集
- Manager の Branch スコープUI
- Guest 読み取りリンク

## プラットフォーム

- Web Push（現場開始リマインド、新しい注意）
- 文書解析（見積PDF → 金額候補。確定は人間）
- 監査ログ閲覧画面（Owner / Executive）

## まだやらない

- 人員自動シフト確定
- 発注自動送信
- ネイティブアプリ
- SSO 本実装
