# 7. MVP機能一覧

MVP の定義: **現場が撮る・話す・押すだけで Graph に残り、監督・経営が「今見るべきこと」を判断できる最小ループ**。

ANDPAD 互換の図面・チャット・検査帳票の網羅はしない。

## 対象ユーザー

| ロール | MVP でできること |
|--------|------------------|
| Worker / Supervisor | Today、現場開始/終了、写真、音声報告、確認質問 |
| Manager / Executive | Management Today、注意の確認 |
| Office | CSV インポート、顧客・メンバー、PDF/写真一括 |
| Owner | 上記 + メンバーとロール |
| Partner | 割当現場の Today（財務なし） |
| Guest | 対象外（枠のみ） |

## 機能リスト

### 基盤

- サインイン（Supabase Auth: email magic link + パスワード）
- Organization 作成、招待
- システム8ロール、権限チェック、RLS
- Branch / Department はテーブルのみ。設定UIは出さない（強制しない）
- audit_logs（金額変更、確定、ロール、インポート、削除）
- PWA インストール可能な manifest / 大きなタッチターゲット

### Today（現場）

- 今日行く現場、開始時間、住所、地図リンク、担当者、必要資料、今日の作業、注意事項
- 現場開始 / 写真を撮る / 音声で報告 / 現場終了
- 経営数値・複雑なメニューを出さない

### Zero Input

- 音声 → 文字起こし → 構造化候補
- 高信頼度かつマスタ照合できた項目は自動採用（確定フラグ付き）
- 低信頼度は一問ずつ「HI25 12本で合っていますか？ はい / 修正」
- 確定後: 作業・場所・担当・人工・材料・時間・進捗・翌日予定・日報生成

### 写真

- カメラ / ライブラリ
- 案件・日時・工程・撮影者・場所・カテゴリを推定して保存
- 閲覧はフィルタ（案件 / 日付 / 工程 / カテゴリ）。フォルダ作成UIなし

### Construction Graph（入力は最小、器は先行）

- 案件: 名称、顧客、建物種別、工種、規模、エリア、築年（任意）、工期、担当
- 財務: 請負・見積合計・予算合計・実績原価の合計（内訳明細UIは最小）
- 工程の簡易リストと進捗
- 人工・材料使用（主にキャプチャから）
- 追加/変更、インシデント、教訓は登録できればよい（専用の重い画面は作らない）

### Similar Projects

- 新規案件時にルールスコアで類似一覧
- 「類似現場 n件 / 平均工期 / 平均人工 / 平均粗利率 / 変化の件数」が出せるデータまで
- Embedding はインタフェースのみ

### Decision Engine

ルール検出のみ:

- 工程: 予定終了が近いのに進捗が低い → 注意
- 人工: 予定比超過 → 注意
- 類似: 同タイプで変更工事が多ければ → 推奨（確認してほしいこと）
- 知識: 工種・建物種別に紐づくノウハウを Today の注意事項へ

表示ラベルは 推奨 / 注意 / 予測 のみ。自動で工程や発注を変えない。

### Management

```
今日    稼働現場 / 完了予定 / 遅延注意
注意    案件名 + 一文（予定比など）
今月    売上見込 / 粗利見込 / 完工予定 / 赤字リスク
```

グラフの壁は作らない。

### Company Knowledge

- 一文ノウハウの登録
- 案件 / 工種 / 建物種別 / 作業 / トラブル への紐付け
- 類似・Today に出す

### 乗り換え

- CSV: 案件 / 顧客 / メンバー
- 写真一括、PDF一括（案件指定または後で紐付け）
- `import_jobs` / `import_rows` → Graph Repository。ANDPAD/KANNA 専用はクラス枠のみ

### AI の範囲（MVP）

使う: 音声認識、自然言語→構造化、（分類信頼度が低い写真のみ）カテゴリ推定  
使わない: 原価、粗利、工期、権限、CRUD、通知判定、類似スコア

## 意図的にやらないこと（MVP）

- 社内チャット、図面ビューア、検査デジタル帳票の完全セット
- 請求・支払の会計ソフト化
- AIチャット窓口
- カスタムロール編集UI（テーブルとシードは用意。編集は Phase 2）
- 本格予測モデル（遅延確率のML）
- React Native
- SSO / SCIM / IP / 端末 / MFA の実装（設定枠のみ）

## 受け入れの目安

1. 職人が Today から音声1回 + 確認0〜数問で、日報相当が残る
2. 写真がフォルダなしで当日現場に紐づく
3. 管理職がログインして「注意」だけで動ける
4. CSV で案件が Graph に入り、類似が1件以上出る
5. Worker で財務が見えないことを RLS で確認できる
