# Auth メールのテンプレート（日本語）

Supabase ダッシュボード → Authentication → Emails → Templates に、次の件名と本文を貼り付けます。

| テンプレート | 件名 | 本文ファイル |
| --- | --- | --- |
| Confirm signup | 【KENBEI】メールアドレスの確認 | confirmation.html |
| Invite user | 【KENBEI】KENBEIへのご招待 | invite.html |
| Magic Link | 【KENBEI】ログイン用リンク | magic_link.html |
| Change Email Address | 【KENBEI】メールアドレス変更の確認 | email_change.html |
| Reset Password | 【KENBEI】パスワードの再設定 | recovery.html |

ロゴは `https://app.kenbei.jp/icon-192.png` を読み込みます。
